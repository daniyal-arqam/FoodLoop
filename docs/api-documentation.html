FoodLoop API documentation

Public clients call the API gateway only (http://localhost:8080). Envelope: { success, message, data }. Authenticated routes: Authorization: Bearer JWT.

Auth /api/auth

MethodPathAuthPurpose
POST/api/auth/registerNoProvider or Organization. Admin rejected.
POST/api/auth/loginNoReturns accessToken
POST/api/auth/logoutYesClient discards token
GET/api/auth/meYesCurrent user
GET/api/auth/admin/usersAdminList users
PATCH/api/auth/admin/users/:idAdminActivate/deactivate

Food /api/foods

MethodPathAuthPurpose
POST/api/foodsProviderCreate Available listing
GET/api/foodsYesSearch/filter
GET/api/foods/:idYesDetails
PATCH/api/foods/:idProvider/AdminUpdate quantity and fields
POST/api/foods/:id/claimVerified orgAvailable → Reserved
POST/api/foods/:id/collectClaiming orgReserved → Collected

MethodPathAuthPurpose

Matcher /api/matching

POST /score, /find, /impact — FoodMatcher, WasteAnalyzer, SustainabilityCalculator.

AI /api/ai

POST /recommend, /rag/query, /agent. Tools: find_available_food, find_organizations, calculate_match_score, generate_match_recommendation.
