# Waste-reduction practices for surplus kitchens

Track leftover volume by day and category before changing production. A cafeteria that repeatedly has 120 prepared meals left after service should shorten the last cooking batch, not only donate the remainder.

List surplus on FoodLoop as soon as the leftover quantity is known, with a pickup window that still leaves time for organizations to travel. Keep allergen notes that the kitchen already records.

Do not use donation as a substitute for production planning. Donation is the last useful step after the kitchen has already reduced over-prep. Record which listings expire unclaimed so the next week's batch sizes can be trimmed.

Prepared trays, bakery, and produce have different leftover patterns. Separate them in the listing category field so the matcher can score organizations that actually need that category.
